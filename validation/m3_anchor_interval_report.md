# 独立校正したアンカーの区間と受験者SD

開発版の `with_anchor_sensitivity(..., intervals=True)` で、同じ対比・同じ点推定について、アンカー値を所与とした区間と、独立校正の全共分散を含む区間を表示する。受験者の固定SDを変えると、同じデータでも点推定と区間が動きうる。ここでは[M3のSDシミュレーション](m3_facet_sd.md)の第1反復を再利用し、公開Python APIの計算と照合した。

## 被覆の根拠

標準正規の独立校正の元検証で、二重採点6人の条件付き被覆は467/500、伝播後は468/500。伝播後の95% Wilson区間は91.1–95.4%で、M2の下限92%の目安を下回った。24人では471/500から475/500になり、伝播後のWilson区間92.7–96.6%は目安を満たした。24人配置でも本番の生成SDが0.5または1.5で分析SDを1に固定した前回の検証では、伝播後の被覆は88.0%・92.0%だった。件数と計算の成功に加えて、実際の割付とモデルの仮定が適用範囲を決める。[独立校正500反復](m3_independent_anchors.md)・[SD誤指定の結果](m3_facet_sd.md#受験者sdの設定と評価者差)

開発版の結果は95%のモデル近似で、`CoverageQualified` と `SupportsFormalInference` はともに `False`。指定した分析の設計・仮定について被覆の根拠を確認して使う。校正と本番の独立性は標本の抽出過程で判断し、同じ名前空間の作品IDで重複を照合する。独立校正と指定して重複IDが見つかったとき、または共有校正についてID・共分散行列だけを渡したときは伝播を保留する。校正元の分析結果を渡す場合は、開発版の共有校正区間を計算できる。[共有校正の利用例](../docs/python_library.md#use-a-calibration-project-with-shared-works)

## 二重採点24人の例

本番の生成SDは1.5、真の R3 − R1 は+1.20 logit。独立した完全交差の校正標本からR1・R2の厳しさを推定した。以下は同じ本番評定で、固定する受験者SDを切り替えた結果。判定が変わる値の例として+2.0 logitを指定した。

| 条件 | 点推定 | 条件付き95%区間 | 校正誤差を含む95%区間 |
|---|---:|---:|---:|
| 独立校正アンカー、SD 1 | +1.247 | [0.747, 1.747] | [0.733, 1.761] |
| 独立校正アンカー、SD 1.5 | +1.511 | [0.901, 2.122] | [0.890, 2.133] |

SDを1に固定した場合の伝播後区間は+2.0を含まず、SD1.5では含む。校正誤差を足す操作だけでは点推定は動かない。受験者SDは尤度に入るため点推定も区間幅も変わる。アンカーを使う区間の設定では受入側の能力平均を推定し、アンカーなしではゼロに固定する。表の `PersonMean` に設定を記録する。

公開APIの点推定・SEを、同じ保存済みシナリオの二重採点6人・24人の両方で照合した。校正共分散ゼロ、共分散ラベルの順序、重複ID、保存後の再読込を回帰テストで検証した。[テスト](../tests/test_python_library.py)・[反復別の参照値](evidence/m3_facet_sd.csv.gz)

## 再現

```sh
python -m validation.m3_anchor_interval_report validation/evidence/m3_anchor_interval_example.mfrm --read
```

別の出力先を指定して `--read` を外すと、保存済み反復の第1例から再作成できる。公開APIの `tables(analysis, "Anchor sensitivity intervals")`、CSV、HTMLで同じ列を確認できる。[保存例](evidence/m3_anchor_interval_example.mfrm)
