# 受験者・課題・評価者のばらつきとアンカー感度

どの相のばらつきが変わると、疎な採点で指定した評価者差の推定、区間、アンカーの影響が変わるか。評価者の厳しさの生成SDを疎な割付と交差させたWind・Jones・Grajeda（2023）を参照した。ここでは評価者差 $R3-R1$ と独立校正アンカーの区間に焦点を置き、受験者SDと課題SDも個別に動かした。[Wind et al.（2023）](https://doi.org/10.1177/01466216231182148)

## 設計

M2と同じ60人・4課題・3評価者の4カテゴリ加法RSM。二重採点は6人または24人で、各評価者対に均等に配分し、合計は各240評定・評価者あたり80評定。500反復について、9つの生成条件で本番受験者の標準正規乱数・潜在評定用の一様乱数・割付を共有した。課題難度と評価者厳しさは名前の付いた有限の水準に対する設定値で、下表のSDには分母4・3を使う。推定では課題と評価者を固定効果として扱う。

| 生成条件 | 受験者SD | 課題SD | 評価者SD | 真の R3 − R1 |
|---|---:|---:|---:|---:|
| 基準 | 1.00 | 0.56 | 0.49 | 1.20 |
| 受験者の水準が近い | 0.50 | 0.56 | 0.49 | 1.20 |
| 受験者の水準が広い | 1.50 | 0.56 | 0.49 | 1.20 |
| 課題の難度が近い | 1.00 | 0.25 | 0.49 | 1.20 |
| 課題の難度が広い | 1.00 | 1.25 | 0.49 | 1.20 |
| 評価者の厳しさが近い | 1.00 | 0.56 | 0.10 | 0.24 |
| 評価者SD大・R2が厳しい | 1.00 | 0.56 | 0.98 | 1.20 |
| 評価者SD大・R2が甘い | 1.00 | 0.56 | 0.98 | 1.20 |
| 3相とも広い・R2が厳しい | 1.50 | 1.25 | 0.98 | 1.20 |

評価者SD大の2条件の生成値 $(R1,R2,R3)$ は $(−1.2,+1.2,0)$ と $(0,−1.2,+1.2)$。SDと対象対比の真値を揃えたまま、もう一人の評価者の位置とR1・R2の相対位置が変わる。評価者の厳しさが近い条件は基準値を0.2倍するため、真の対比が小さい。課題の条件は基準の4課題の難度を比例拡大・縮小した。

すべての生成条件で、本番の能力SDを1に固定して、アンカーなし、R1・R2を真値に固定、R1の固定値だけ+0.4 logit誤指定、独立標本から推定したR1・R2を固定、の4種類を適合した。本番の生成SDが1以外のときは、生成SDを既知とするアンカーなし・独立校正アンカーの適合も追加した。校正側は各条件で別の60人・完全交差720評定、能力SDは常に生成・適合とも1。課題と評価者の真値は本番と校正で共通。求積61点の直接MMLと観測情報による95% Wald区間を使った。推定したアンカーでは、同じ点推定について固定値に条件づける区間と、独立校正の全共分散を伝播する区間を計算した。[独立校正の計算](m3_independent_anchors.md#区間と照合)

## 受験者SDの設定と評価者差

本番側42,000適合すべてで指定対比の割付が支持され、この検証用の計算では区間を返した。以下の被覆率は各500反復。平均バイアスは推定値から各条件の真値を引いた平均。表の右側は同じデータで独立校正の全共分散を含めた区間の結果。

| 真の本番SD | 二重採点 | アンカーなしのバイアス、SD 1 → 真のSD | 同・被覆率 | 推定アンカーのバイアス、SD 1 → 真のSD | 同・被覆率 |
|---:|---:|---:|---:|---:|---:|
| 0.5 | 6人 | +0.315 → +0.043 | 89.6% → 93.6% | +0.245 → +0.043 | 91.6% → 92.8% |
| 0.5 | 24人 | +0.301 → +0.030 | 86.4% → 95.4% | +0.229 → +0.028 | 88.0% → 95.2% |
| 1.5 | 6人 | −0.202 → +0.038 | 86.0% → 92.8% | −0.134 → +0.047 | 87.6% → 92.6% |
| 1.5 | 24人 | −0.205 → +0.032 | 87.4% → 96.4% | −0.145 → +0.033 | 92.0% → 95.6% |

SDの誤指定に伴うバイアスの方向は、高く固定するか低く固定するかで逆だった。被覆は24人配置でも低かった。対応のある各反復の被覆判定から計算すると、24人・固定なしで真のSDに合わせた被覆の改善は0.5条件・1.5条件とも9.0ポイントで、差の95%モンテカルロ区間はどちらも小数第1位まで6.1〜11.9ポイント。SDを1.5に合わせると固定なしの24人配置で区間幅中央値は1.148から1.397 logitへ広がった。6人配置ではバイアスが縮んでも推定のばらつきが増え、固定なしの対比RMSEは0.470から0.512 logitへ増えた。

3相とも広い24人配置では、固定なしの被覆は88.6% → 95.4%、独立校正アンカーでは95.6% → 95.8%だった。後者の対応のある変化0.2ポイントの95%モンテカルロ区間は−0.7〜+1.1ポイント。この設定ではアンカーの固定がSD誤指定の影響を弱め、平均バイアスはSD1で+0.009、SD1.5で+0.015 logitだった。6人配置の同じ分析では90.4% → 93.6%で、真のSDでの被覆率の95% Wilson下限は91.1%だった。組合せと割付の両方が結果に関わる。

## 課題SD・評価者SDと分離

二重採点24人、アンカーなし、分析の能力SD1で比較した。$G$ は各相の推定された標準偏差から測定誤差分を除いた分離で、観測情報から再構成したモデルSEを使う。結果は反復別統計の中央値。

| 生成条件 | 0または3の評定 | 課題の G | 評価者の G | R3 − R1 の区間幅（logit） |
|---|---:|---:|---:|---:|
| 基準 | 47.1% | 4.15 | 3.51 | 1.184 |
| 課題SD 0.25 | 45.0% | 1.95 | 3.60 | 1.168 |
| 課題SD 1.25 | 55.0% | 7.69 | 3.33 | 1.262 |
| 評価者SD 0.10 | 45.4% | 4.22 | 0.63 | 1.126 |
| 評価者SD 0.98・R2が厳しい | 51.7% | 3.87 | 6.48 | 1.221 |
| 評価者SD 0.98・R2が甘い | 51.7% | 3.95 | 6.46 | 1.224 |

課題間や評価者間の生成上の差が広がると、その相の分離は高くなる。広い課題条件では端の評点が増え、同時に評価者対比の区間も広がった。受験者側でも、基準から真の受験者SDを1.5に広げ、分析をSD1のままにすると、EAPの経験的信頼性の中央値は0.697から0.750、生成水準に対するRMSEは0.563から0.792 logitに増えた。経験的信頼性は対象内のばらつきに照らした分離、RMSEは測定誤差の絶対量を表す。真のSDを用いた場合でもこの条件のRMSEは0.692 logitだった。

## アンカーの誤指定と評価者の位置

二重採点24人でR1を+0.4 logitずらすと、真値アンカーの場合に比べ、R3 − R1の点推定は基準で平均−0.210 logit、評価者SD大・R2が厳しい場合は−0.200、R2が甘い場合は−0.145 logit動いた。後二者の差は−0.055 logit、対応のある95%モンテカルロ区間は−0.057〜−0.053 logit。SDが同じでも、アンカーにした水準と対象評価者との位置関係で影響が変わった。

真の対象差が+0.24 logitの狭い評価者条件では、同じ誤指定で平均−0.200 logit動いた。負の点推定は真値アンカーで69/500件、誤指定で215/500件だった。アンカー値の誤差を、対象対比の大きさや符号を変えるかという観点でも点検する。

## 照合と適用範囲

- 基準条件のアンカーなし1,000適合をM2の厳しい停止条件の保存出力と照合し、点推定の最大差は0.000100 logit未満だった。既存の共有校正の第1反復でも、標準正規の計算は従来の点推定・SE・摂動照合と $10^{-9}$ 以内で一致した。
- 全9条件の最初の二重採点24人データをTAM 4.3.25で適合し、分析SDをそろえた12設定で、アンカーなしと独立校正アンカーの対比を照合した。点推定の最大差は0.0000033 logit、観測情報のSEと校正誤差伝播後SEの最大差は0.0000016 logitだった。[TAMの照合値](evidence/m3_facet_sd_tam.csv)
- この結果は固定された3人・4課題の配置、独立校正、加法RSMに対応する。受験者の真のSDを与えた条件はモデルの誤指定を切り分けるための基準である。PCM、共有校正との組合せ、受験者SDをデータから推定する方法の性能は今回の検証範囲外。[全反復の出力](evidence/m3_facet_sd.csv.gz)

## 再現

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
  python -m validation.m3_facet_sd /tmp/m3-facet-sd.csv --workers 6
gzip -n -c /tmp/m3-facet-sd.csv > /tmp/m3-facet-sd.csv.gz
```

同じCSVを指定すると完了済みの反復を再利用できる。TAMの入力は同じ関数で第1反復を再生成する。

```python
import pandas as pd
from validation.m3_facet_sd import calibration_ratings, validation_designs

source, receiving = [], []
for profile, design, _, items, raters, _, data in validation_designs(1):
    if design == "balanced24":
        source.append(calibration_ratings(1, items, raters).assign(profile=profile))
        receiving.append(data.assign(profile=profile))
pd.concat(source).to_csv("/tmp/m3-sd-tam-source.csv", index=False)
pd.concat(receiving).to_csv("/tmp/m3-sd-tam-receive.csv", index=False)
```

```sh
Rscript --vanilla validation/m3_facet_sd_tam.R /tmp/m3-facet-sd.csv.gz \
  /tmp/m3-sd-tam-source.csv /tmp/m3-sd-tam-receive.csv /tmp/m3-sd-tam.csv
```
