# 群間DFFの区間を読み、比較を支える評定を確認する

同じ480評定で、固定SD MMLの95%区間はゼロを含み、mfrmrのCMLの区間はゼロを含まなかった。区間の読み方が推定法で変わる例として、能力SDの感度分析から第13反復を選んだ。A・B校は各60人、4課題を共通の5段階尺度で採点する。生成上はA校の能力SDが1、B校は1.5で、B校のR3だけを+0.5 logit厳しくした。指定対比は $(R3-R1)_B-(R3-R1)_A$。正の値はR3のR1に対する相対的な厳しさがB校で大きいことを表す。[反復実験と適合条件](m5a_school_variance.md#能力sd差と真のdffが共存する場合)

| 評定と推定法 | R1・R3の共通採点（A校 / B校） | 推定値 | SE | 95%区間または保留 |
|---|---:|---:|---:|---|
| 480評定・mfrmpy 固定SD MML | 20 / 20 | +0.593 | 0.321 | [−0.036, +1.222] |
| 同じ480評定・mfrmr CML | 20 / 20 | +0.984 | 0.412 | [+0.177, +1.792] |
| B校の二重採点48評定を欠く432評定 | 20 / 0 | — | — | 作品ごとの水準を自由にすると指定対比を識別できない |

推定値・SE・端点の単位はlogit。MMLの区間にはゼロと+0.5 logitの両方が入り、この例で想定した大きさの差を排除できない。CMLの下限は正で、点推定も区間幅もMMLより大きい。能力分布の指定を要しないCMLを併記すると、同じ評定に対する推定法の感度を示せる。検出力と被覆率は各条件の全500反復から求めた。[固定SD MMLの保存結果](evidence/m5a_school_variance_nonzero.csv.gz)・[同じ評定のCML結果](evidence/m5a_school_variance_nonzero_cml.csv.gz)

## どの作品・課題を点検するか

1. `Group DFF shared works` の `Group`・`Path`・`WorkIDs` から、どの学校で、どの作品が指定対比の観測上の経路を支えるかを確認する。この例では両校ともR1–R3の直接経路。`Group DFF assignment coverage` では予定と実測の人数を照合できる。
2. 共有作品IDを元の評定の `School`・`Person` に照合し、`Item` ごとにR1・R3の点数を並べる。再現コマンドで、両校に共通採点がある例では各校40組の受験者×課題について点数対を `shared-scores.csv` に出す。たとえばB校のB002では、I3はR1が5点・R3が2点、I4は4点・3点。実データでこのような差を調べるときは、該当作品と課題の段階別記述、採点記録を照合する。この合成例には点数と割付があり、作品の内容や採点者の判断理由は含まれない。
3. `bias_requests` の学校×評価者・課題別の診断がある場合は、ずれの大きいセルを点検候補にする。診断は校正値を固定した得点予測子のずれ。指定対比はR3とR1の厳しさの差を両校間で比較した値であり、元の点数差や固定校正の診断は別の量を表す。[固定校正のバイアス診断](m4_rater_task.md)・[群間DFFの量の違い](m5a_group_dff.md#mfrmrとtamでの確認)

B校の対照では二重採点予定だった24人について、片方の評価者の2評定ずつを除いた。予定上の共通採点は両校20人、実測ではA校20人・B校0人。`Group DFF assignment discrepancies` の `RestoresContrastOnItsOwn` は、未取得48セルのうち40セルで、その1セルを補うと観測上の識別が回復することを示す。これは識別の確認であり、追加一評定でどれだけ区間が狭くなるかは別途評価が必要になる。

## 開発版での報告範囲

| 保存したモデルと割付 | 報告する内容 |
|---|---|
| 支持される指定対比で、数値検査も通る | アンカーのない5段階・共通課題の固定SD RSMで、事前指定した一つの対比の点推定、モデル近似の区間とWald値、共通作品の経路を出す。 `CoverageQualified`・`SupportsFormalInference` はともに `False`。 |
| 観測は対比を支え、点推定は有効だが区間の根拠が不足 | 点推定と区間の保留理由を示す。区間用の数値情報を保存していない旧ファイルもここに含む。 |
| 観測が指定対比を支えない | 対比を保留し、理由と観測された経路を示す。予定表があれば未取得セルも示す。 |
| CMLの感度分析 | mfrmrで同一評定に適合した対比と区間を、使用した推定法を添えて利用例で併記する。上表のCML結果は外部の反復別記録から参照する。 |

等分散の20人配置では、固定SD MMLの帰無条件と+0.5 logit条件がともに返却率・被覆の基準を満たした。B校の能力SDが1.5で真の差が+0.5 logitの場合は、固定SD MMLの被覆率が91.8%に下がり基準を下回った。CMLも等分散の帰無条件では被覆基準に届かず、SD差と真の差がある条件では500件中3件に有限解がなかった。実データで区間を読む際は、仮定と割付の違いを記録し、ゼロを含む場合も実務上重要な差が区間に含まれるかを確認する。[等分散の検証](m5a_direct_overlap.md#各条件500反復の結果)・[能力SDの感度分析](m5a_school_variance.md)

## プロジェクトを再読込する

公開Python APIから作った二つの `.mfrm` を、リポジトリのルートから読み直す。`--exports` は `figures` extra を使い、図・HTML・CSVと、共通課題の元の点数対を指定ディレクトリに出す。

```sh
python -m validation.m5a_dff_report validation/evidence --read --exports /tmp/m5a-dff-report
```

再適合する場合は、最初の引数に新しい出力先を指定して `--read` を外す。数値と判定は、プロジェクト保存前後の公開APIと、保存済みの反復別結果を照合した。mfrmrのCMLも同じ480評定で再適合し、保存値を確認した。図・CSV・HTMLは同じMMLのモデル近似区間または保留理由を表示する。

[480評定のプロジェクト](evidence/m5a_dff_sd_difference.mfrm)・[B校の共通採点がないプロジェクト](evidence/m5a_dff_missing_shared_works.mfrm)・[実行コード](m5a_dff_report.py)

## 0.2.3.dev3のインストール候補での確認

候補から480評定・432評定を作成して再読込し、上記のMML推定値・SE・区間・Wald値を保存済みの反復結果と照合した。共有作品から元評定への対応、実測の重複20/20と20/0、識別を回復する未取得40セルも一致した。CMLは既存の同一評定の計算記録を再利用した。

再適合を禁止した再読込後も、表・図・CSV・HTML・UTF-8 `.out`・図表ZIPを作成できた。古い保存例の区間が実行環境・ソースの検査で保留されることと、今回の候補で作った例の区間が返ることを区別する。配布先への公開完了はこの検証に含めない。
